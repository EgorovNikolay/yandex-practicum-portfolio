# Спринт 4: Расследование подозрительного использования привилегированной учётной записи

## Описание
Расследование инцидента, связанного с компрометацией учётной записи администратора `Demo.lab\administrator` на сервере `APPSERVER (10.0.0.10)`. 20 марта 2025 года зафиксирован вход из необычного географического региона (Германия, IP `45.14.164.3`) в нерабочее время (03:15 по локальному времени), чтение конфиденциальных файлов и изменение прав доступа к папке `Finance` на `Everyone:FullControl`.

## Цели
- Проанализировать логи Windows в ELK для выявления аномалий.
- Выявить индикаторы компрометации (IoC).
- Доработать 4 правила корреляции с ошибками.
- Исправить ошибки в плейбуке реагирования.
- Создать кейс в TheHive с привязкой MITRE ATT&CK.
- Провести анализ индикаторов через SOAR (Cortex).
- Подготовить отчёт с рекомендациями.

## Инструменты
- **ELK Stack** — анализ логов (индекс `winlogs`).
- **Elastic Security** — доработка правил корреляции.
- **TheHive** — создание кейса, observables, SOAR-анализ.
- **Cortex** — обогащение индикаторов.
- **MITRE ATT&CK** — классификация техник.

## Результаты
### Выявлены индикаторы компрометации (IoC):
- **IP-адрес:** `45.14.164.3` (Германия)
- **Учётная запись:** `Demo.lab\administrator`
- **Затронутые файлы:**
  - `\\srv-file\Finance\Confidential\Confidential.docx`
  - `\\srv-file\HR\Confidential\Confidential.docx`
  - `\\srv-file\Executive\Strategy\Confidential.docx`
- **Изменения:** Права доступа к папке `Finance` установлены на `Everyone:FullControl`.

### Классифицированы техники MITRE ATT&CK:
 ID  Техника  Этап 
 T1078  Valid Accounts  Initial Access
 T1222  File and Directory Permissions Modification  Defense Evasion
 T1083  File and Directory Discovery  Collection

### Исправлены правила корреляции (4 шт.):
1. **Обнаружение входов в нерабочее время** — замена `event.action: "LogonTime"` на `event.code: 4624`.
2. **Обнаружение входов из необычного региона** — убрана привязка к конкретной учётной записи.
3. **Обнаружение подозрительной активности с файлами** — добавлено событие `ShareModify`.
4. **Обнаружение изменений в настройках файловых ресурсов** — исправлена маска события на `*ShareModify*`.

### Исправлен плейбук реагирования:
- Добавлены проверки контекста (график работы, VPN, командировки).
- Исключено использование пороговых значений как единственного критерия.
- Уточнены каналы связи (не использовать корпоративную почту).
- Добавлены шаги по изоляции, сохранению логов и анализу воздействия.
- Внесены этапы восстановления и извлечения уроков.

### Создан кейс в TheHive:
- Название: «Подозрительное использование учётной записи администратора».
- Приоритет: High.
- Статус: Resolved.
- Привязана техника MITRE ATT&CK (T1078).
- Добавлены observables (IP, учётная запись).
- Выполнен SOAR-анализ через Cortex.

## Рекомендации
- **Немедленно:** сменить пароль администратора, отменить права `Everyone:FullControl`, проверить другие системы.
- **Среднесрочно:** внедрить MFA, настроить геоблокировку.
- **Долгосрочно:** усилить мониторинг аномальных входов, обновить правила корреляции.

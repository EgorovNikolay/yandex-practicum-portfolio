# Спринт 5: Расследование целевой фишинговой атаки с компрометацией контроллера домена

## Описание
Расследование целевой кибератаки на компанию Demo Lab, произошедшей 15 апреля 2025 года. Злоумышленник с использованием фишингового письма с вредоносным вложением `Financial_Report_Q1_2025.exe` получил доступ к рабочей станции сотрудника (`ws7`, IP `10.0.0.27`), затем скомпрометировал контроллер домена (`dc01`, IP `10.0.0.10`) и файловый сервер (`fileserver`, IP `10.0.0.15`), похитив конфиденциальные данные объёмом около 39 МБ.

## Цели
- Провести полное расследование инцидента.
- Выявить все этапы атаки (фишинг → выполнение → закрепление → разведка → боковое перемещение → сбор данных → эксфильтрация → сокрытие следов).
- Собрать индикаторы компрометации (IoC).
- Классифицировать атаку по MITRE ATT&CK (минимум 8 техник).
- Настроить и исправить правила корреляции.
- Подготовить технический и управленческий отчёты.
- Разработать плейбук реагирования.
- Создать отчёт по приоритизации правил корреляции.

## Инструменты
- **ELK Stack** — анализ логов (индекс `win`).
- **Velociraptor** — сбор хешей файлов.
- **MITRE ATT&CK** — классификация тактик и техник.
- **SIEM (Elastic Security)** — настройка и исправление правил корреляции.

## Рекомендации
- **Немедленно:** внедрить MFA для административных учётных записей, фильтрацию вложений `.exe`, сменить пароли, заблокировать C2-адреса.
- **Среднесрочно:** внедрить сегментацию сети, усилить политику паролей, развернуть EDR, обучить сотрудников.
- **Долгосрочно:** создать плейбуки, настроить мониторинг в SIEM, проводить регулярные учения, внедрить Threat Intelligence.
